# Tests de charge Prisma / Postgres (local)

Date du rapport : 2025-11-06

## Contexte

- Postgres jetable : **Docker** — `docker compose -f docker-compose.perf.yml up -d` (port **54333**, extension `pg_trgm` via `scripts/perf/init-pg.sql`).
- **Preuve d'exécution (cet agent)** : Docker absent sur la VM CI — PostgreSQL 16 installé localement (`pg_ctlcluster 16 main start`), base `perf_load`, utilisateur `perf`, port **5432**. Variable : `PERF_DATABASE_URL=postgresql://perf:perf@127.0.0.1:5432/perf_load?schema=public`.
- Variable équivalente Docker : `postgresql://perf:perf@127.0.0.1:54333/perf_load?schema=public`.
- Ce dépôt ne contenait pas de schéma applicatif Prisma ; un schéma **minimal dédié aux benchmarks** a été ajouté sous `prisma/`.
- Les mesures comparent **sans** puis **avec** les index de migration `20251106140100_*`.
- `EXPLAIN ANALYZE` : `PERF_EXPLAIN=1 npm run perf:load-test` (un plan est affiché pour `listContactsFiltered` en phase « après index »).

## Relancer la suite

```bash
# Avec Docker (recommandé sur poste de dev)
npm run perf:ci-local
```

```bash
# Postgres local (sans Docker) — adapter le port si besoin
export PERF_DATABASE_URL='postgresql://perf:perf@127.0.0.1:5432/perf_load?schema=public'
npx prisma generate && npx prisma migrate deploy
npm run perf:all-scales && PERF_REPORT_DATE=2025-11-06 npx tsx scripts/perf/write-report.ts
```

## Migrations et optimisations

- `20251106140000_init_crm_load_test` : tables Contact, EmailCampaign, EmailCampaignContact, PapSession, FormInbound.
- `20251106140100_add_load_test_indexes` : index de jointure, file formulaires, liste contacts (statut + ville + tri), index GIN trigram pour recherche type tableau de bord.
- Les scénarios Prisma utilisent `select` ciblé (pas de N+1 sur les agrégats — tableaux de bord en transaction).

## Risques

- Schéma et scripts sont **à des fins de benchmark local** ; toute réutilisation en production nécessiterait alignement métier et revue d'index.
- L'index GIN trigram augmente légèrement le coût des écritures sur `Contact`.
