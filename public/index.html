annecy-sig-mcp

Serveur MCP (Model Context Protocol) lecture seule pour les couches ArcGIS REST du portail SIG de la Ville d'Annecy. public-only

Endpoints

  • /api/health — diagnostic léger (aucun appel ArcGIS)
  • /api/mcp — endpoint MCP Streamable HTTP (Bearer token requis)

Utilisation depuis Cursor

{
  "mcpServers": {
    "annecy-sig-remote": {
      "url": "https://mcp.leadalpes.fr/api/mcp",
      "headers": {
        "Authorization": "Bearer <MCP_PUBLIC_READ_TOKEN>"
      }
    }
  }
}

Sécurité

  • Lecture seule — aucun écrit ne quitte ce code.
  • mode = internal est explicitement refusé sur le transport HTTP.
  • Outils internal (list_current_works, list_late_works, generate_internal_dashboard_brief) non exposés.
  • Source : github.com/Damso74/annecy-sig-mcp
